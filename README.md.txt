# Explore With Me (Микросервисная архитектура)

Сервис для поиска и публикации событий. Проект переведён из монолитной архитектуры в микросервисную с использованием Spring Cloud.

##  Стек технологий
- **Java 21**
- **Spring Boot 3.3.0**
- **Spring Cloud** (Eureka, Gateway, Config Server, OpenFeign)
- **Spring Data JPA** (PostgreSQL)
- **Docker & Docker Compose**
- **Postman** (для тестирования API)

## Архитектура проекта

Проект разделён на следующие микросервисы:

1. **`user-service`** — сервис управления пользователями.
2. **`event-service`** — сервис управления событиями и категориями.
3. **`request-service`** — сервис обработки заявок на участие в событиях.
4. **`compilation-service`** — сервис подборок событий.
5. **`comment-service`** — сервис комментариев к событиям.
6. **`stats-server`** — сервис сбора и хранения статистики просмотров.
7. **`gateway-server`** — API Gateway (единая точка входа, маршрутизация).
8. **`config-server`** — централизованное управление конфигурациями.
9. **`discovery-server`** — Eureka Server (реестр микросервисов).
10. **`common`** — общий модуль с исключениями.

## Межсервисное взаимодействие
- Сервисы регистрируются в **Eureka Server**.
- Общение между сервисами происходит через **OpenFeign** (с поддержкой кэширования @Cacheable и отказоустойчивости).
- Внешние запросы проходят через **Spring Cloud Gateway** (`gateway-server`), который маршрутизирует их на нужные сервисы.
- Конфигурации хранятся централизованно в **Config Server**.

## Как запустить проект

### Требования
- Docker Desktop
- Java 21 (для локального запуска отдельных модулей)
- Maven 3.8+

### Запуск через Docker Compose
1. Соберите проект:
   ```bash
   mvn clean install -DskipTests
2. Подождите 30-40 секунд, пока все сервисы зарегистрируются в Eureka.
3. API доступно по адресу: `http://localhost:8080`
4. Панель Eureka: `http://localhost:8761`

### Локальный запуск (для разработки)
1. Запустите discovery-server и config-server.
2. Запустите нужные микросервисы через IntelliJ IDEA.

### Тестирование
В корне проекта находится коллекция Postman для тестирования API (Test Explore With Me - Feature).

#### Для запуска тестов:
1. Убедитесь, что все сервисы запущены.
2. Импортируйте коллекцию в Postman.
3. Запустите Runner и убедитесь, что все тесты проходят успешно (статус 200/201/409 в зависимости от сценария).
